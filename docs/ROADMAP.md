# Variable roadmap

1. **Phase 1–3 and 4.5A — complete:** JavaFX shell, restrained theme, tabs, file picker/drop support, safe TXT/PNG/JPEG/PDF handling, core detection/routing boundaries, and bounded PDF rendering/navigation, and PDF performance hardening (visible-page lookup, byte-bounded cache, stale-result rejection, HiDPI-sharp rendering).
2. **Next:** broaden and test the core routing model, including a clear viewer capability contract.
3. **Future PDF refinement:** improve viewport prioritization and add a global context-aware toolbar if later usability testing justifies it.
4. **Phase 4:** add recent files, preferences, keyboard shortcuts, and viewer-specific toolbar controls.
5. **Phase 5:** investigate structured formats and archive listings; rendering quality will be documented rather than assumed.
6. **Phase 6:** package Variable for macOS and plan Windows/Linux distribution.
